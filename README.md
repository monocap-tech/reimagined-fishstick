# Relay Yard — CPSC 386 Project 2

Minimal original 2D puzzle-platformer: traverse a single level, touch three relays, and enter the unlocked gate. This deliberately favors rubric coverage over elaborate game design.

**Status: source and Editor assembler prepared; NOT YET compiled, Unity-tested, built, or submitted.** The AudioMixer must be created in the Unity Editor. Read ASSEMBLY.md and TESTING.md. Do not represent this repository as a playable build until those steps succeed.

## Technical features

1. Input Actions asset (Assets/Input/RelayControls.inputactions), Rigidbody2D, OverlapCircle ground check, jumping.
2. Three trigger-driven relays, HashSet-based pure C# RelayLedger, exit unlock.
3. Persistent DontDestroyOnLoad AudioDirector with original synthesized music/jump/relay/unlock sounds; menu music-volume saved in PlayerPrefs. Separate Music/SFX routing engages after Resources/RelayMixer.mixer is created with those two groups.
4. Two RelayDefinition ScriptableObject assets are generated by the assembler; RelayLedger is a pure C# class.
5. Generated Animator has Locomotion (Idle/Run 1D blend tree), Jump, and Fall states driven by Speed/VerticalSpeed/Grounded.
6. JumpFeedback StateMachineBehaviour triggers sound and particles as a Jump animation state is entered.
7. ParticleSystem.Play() triggered from PlayerMotor and RelayBeacon scripts.
8. SeededBackdrop generates a fixed-seed field of decorative stars; the level geometry stays fixed and beatable.
