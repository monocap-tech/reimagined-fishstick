## Game and controls

Neon Range is a one-screen 2D shooter. Move with WASD or arrow keys and hold Space to fire upward. Each hit on a pink target adds one point and relocates that target inside its lane. The best score is saved immediately. Escape opens or closes a pause menu. Resume continues the run; Quit to Menu ends it and shows the record on the Main Menu.

## Scripts

| Script | Responsibility |
|---|---|
| PlayerController.cs | Reads Move and Fire from the Input Actions asset. Sets Rigidbody2D velocity in FixedUpdate and requests a pooled shot at a timed interval. |
| BulletPool.cs | Instantiates 12 bullets in Awake and disables them. GetFromPool selects an inactive bullet; it grows only when no inactive instance exists. |
| Bullet.cs | Activates at the muzzle, moves upward, detects Enemy tags in OnTriggerEnter2D, scores one hit, and returns by deactivation on impact or timeout. |
| EnemyTarget.cs | Adds a point through ScoreManager and relocates within its assigned rectangle. Targets are reused. |
| ScoreManager.cs | Displays score/best, loads the previous best, and saves each new record using PlayerPrefs.SetInt and Save. |
| MainMenu.cs | Loads Gameplay by scene name and exits a desktop build. Quit also stops Editor Play mode for local testing. |
| PauseManager.cs | Reads the Pause action, toggles the Canvas panel and Time.timeScale, resumes, and restores time scale when leaving the scene. |
| MenuBestScore.cs | Reads and displays the persisted record each time the menu opens. |
| NeonRangeBuilder.cs | Editor-only helper that creates editable art, action references, scenes, tilemap, prefab, UI, tags, layers, and scene-list entries. |
| NeonPulse.shader | Applies a visible time-driven brightness pulse to the targets' shared material. |

Runtime settings use private SerializeField fields. Classes are in the NeonRange namespace. The helper remains under Assets/Editor and is excluded from builds.

## Scenes and GameObjects

**MainMenu:** Orthographic camera, Canvas, and EventSystem. MenuManager connects Start and Quit Game. MenuBestScore reloads the saved record into the Canvas. Start loads Gameplay using SceneManager.

**Gameplay:** ArenaGrid contains Walls, a border painted with square Tile assets and TilemapCollider2D. The Player has Rigidbody2D and BoxCollider2D, so the walls constrain movement. Its Muzzle supplies a launch position to BulletPool. The pool prewarms Bullet prefab instances, which detect tagged Enemy triggers and return by deactivation. Each EnemyTarget talks to ScoreManager. Canvas displays run score and best score. GameManager contains PauseManager, which remains active when PausePanel is hidden. Both scenes use InputSystemUIInputModule for Canvas buttons.
